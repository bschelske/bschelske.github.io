Selected Projects

  • Deep Learning for Tumor Cell Classification (PyTorch, CNN, Transfer Learning): Built and validated CNN pipeline for 1k+ single-cell images from 10+ blood donors, achieving 99.6% accuracy with 5- fold cross-validation. Performed data augmentation to generate synthetic data of minority classes and used SHAP for model interpretation.
  • Development of Microfluidic Devices for Individual Cancer Cell Analysis (AutoCAD, Microfabrication, Microscopy, ImageJ, Pandas): Designed and fabricated a microfluidic device for label-free cancer cell analysis, designed experiments and established a protocol for imaging and analysis. Performed simulations in COMSOL to aid device design and guide experimental parameters.
  • Automated Image Processing Pipeline (Python, OpenCV): Developed an automated image processing pipeline for cancer cell analysis using computer vision and particle tracking, reducing manual data analysis time by 8x.
  • Automated Data Collection and Control of Microfluidic Devices (Python): Created an automated workflow for data collection and manipulation of a microfluidic platform. A user interface and serial control of the microfluidic device improves experimental reproducibility and user productivity.
  • Random Forest Machine Learning Approach for Microfluidic Quality Control (Python, EIS): Trained a random forest model on electrochemical impedance spectroscopy (EIS) data of microfluidic devices to assess device quality for subsequent experiments. The optimized random forest model increases positive experimental outcomes and improves resource efficiency.
